# Badge

Etiqueta corta de estado. Variantes sólidas y outlined: `primary`, `secondary`, `success`, `error`, `warning`, `info`.

## Import

```ts
import { Badge } from "@felipechandiadev/ui";
```

## Props

- `variant`: tono visual.
- `children`: texto de la etiqueta.

## Servidor

Client component. Next lo incluye en el HTML y lo hidrata.

## Ejemplo mínimo

```tsx
<Badge variant="success">Activo</Badge>
```
