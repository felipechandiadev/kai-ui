# Skeleton

Bloque de carga con la forma del contenido que va a aparecer.

## Import

```ts
import { Skeleton } from "@felipechandiadev/ui";
```

## Props

Acepta los atributos de un `div` (`className`, `style`) para definir ancho y alto.

## Servidor

Client component. Next lo incluye en el HTML y lo hidrata.

## Ejemplo mínimo

```tsx
<Skeleton className="h-4 w-32" />
```
